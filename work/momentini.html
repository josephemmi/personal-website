Momentini

A baby tracker built with Claude Code, used daily — for feeds, sleep, and everything else that's hard to remember at 3am.

Built with Claude Code & Supabase

Live

What it does

A responsive web app for tracking a baby's day — feeds, sleep, nappies, and whatever else needs logging when you're too tired to remember it an hour later. Built tablet-first, since it lives propped up on the kitchen counter more than it lives in a pocket.

How it's built

  • Built entirely with Claude Code — the first real production app made this way
  • Supabase backend, with multi-user authentication so both parents can log independently
  • Optimised for iPad/tablet use rather than phone-first
  • A live Linear roadmap feeds directly into the case study, so what's planned is always visible
  • Release notes are auto-generated by a Claude Code automation — not written by hand

Why it exists

Built out of necessity during a demanding stretch with a newborn — the existing baby-tracking apps were either bloated or didn't fit how the day actually works. This does one thing, and it's used every day.
